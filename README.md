I did a single player motorbike racer game which implemented a graphical user interface. Ever user is required to login prior playing the game whereas the user details are stored in a separate text file. During the game, user is able to control the player using keys and separate buttons to pause or restart the game and there exists random starting positions for the bot players, a checkpoint line which the player is supposed to reach within a timeframe. Depending on the game time the player earns points. If the player goes out of bounds a Fall Animation is shown and if the time is over a time over screen is shown. After every game player score is saved with timestamps. Note that I received 103 out of 100 and got the second highest score overall.
